# Aporte a la comunidad: gratuito y de pago mínimo

## Principio

El proyecto debe entregar valor antes de pedir una compra.

La persona que presta su tiempo y explica un problema debe recibir algo útil a cambio.

Esto crea una relación equilibrada:

> Ellos aportan contexto y experiencia. Nosotros aportamos análisis, conocimiento y posibles soluciones.

## Aporte gratuito inicial

El usuario puede recibir una primera orientación sin coste.

Puede incluir:

- reformulación del problema;
- identificación de posibles causas;
- recomendaciones de proceso;
- herramientas existentes que podrían ayudar;
- alternativas de automatización;
- cambios operativos;
- pequeñas acciones prácticas;
- explicación de oportunidades de mejora.

El objetivo no es solucionar necesariamente el problema completo.

El objetivo es que la persona pueda decir:

> "Esta conversación me sirvió."

## Por qué regalar valor

Esto genera varios efectos:

1. aumenta la confianza;
2. mejora la reputación;
3. reduce la percepción de que el usuario está siendo utilizado como fuente de datos;
4. genera recomendaciones;
5. permite que los primeros usuarios se conviertan en promotores;
6. ayuda a validar qué recomendaciones producen resultados.

## Servicio de mayor profundidad

Después de la orientación inicial puede existir una capa de pago para análisis más detallado.

No debe plantearse como un mecanismo artificial para cobrar una cantidad simbólica.

Debe representar trabajo adicional.

Puede incluir:

- análisis detallado del proceso;
- documentación;
- alternativas comparadas;
- estimación de impacto;
- propuesta de mejora;
- definición de requerimientos;
- diseño conceptual de una solución.

## El pequeño pago como señal

Un pago pequeño puede funcionar como señal adicional de compromiso, pero no debe considerarse automáticamente una prueba de intención de compra de software.

La evidencia más fuerte sigue siendo el comportamiento:

**interés → conversación → participación → prueba → aceptación → pago.**

## Equilibrio comercial

La estrategia debe evitar dos extremos:

### Extremo 1
Dar tanto gratuitamente que nunca exista una oportunidad comercial.

### Extremo 2
Utilizar el "diagnóstico gratuito" como una estrategia agresiva de venta.

El principio correcto es:

> **Primero aportar valor real. Después ofrecer profundización cuando exista una necesidad real.**

## Relación a largo plazo

Cada persona que participa puede convertirse en:

- usuario;
- piloto;
- cliente;
- referente;
- fuente de nuevos problemas;
- fuente de nuevos usuarios.

El proyecto busca construir relaciones, no solamente registros.
